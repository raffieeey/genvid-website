# docs/

This folder is the published GENVID site. GitHub Pages serves it from `/docs` at [https://raffieeey.github.io/genvid-website/](https://raffieeey.github.io/genvid-website/).

There is no build step. Pages are plain HTML. CSS is plain and hand-editable.

## Files

- `index.html` - home
- `pricing.html` - credit packs
- `business.html` - product-photo path for businesses
- `trust.html` - AI labels, acceptable use, payments, privacy, support
- `404.html` - not-found page
- `robots.txt` and `sitemap.xml` - crawler files
- Every page head carries canonical, Open Graph, Twitter card and JSON-LD structured data
- `favicon.png`, `logo.jpg`, `og-image.jpg` - brand and social preview
- `css/styles.css` - shared shell and type
- `css/pages.css` - extra page rules when present
- `clips/` - playable `.mp4` samples
- `clips/posters/` - poster stills

Edit copy in the HTML files. Edit colours, type and layout in the CSS files, then refresh the browser. Do not add a bundler or a CSS preprocessor.
